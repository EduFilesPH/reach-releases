# Reach Remote Desktop

Use Reach to connect to your Windows PCs over Tailscale.

[Download the latest Windows installer](https://github.com/EduFilesPH/reach-releases/releases/latest/download/Reach-Setup.exe) or [view release notes](https://github.com/EduFilesPH/reach-releases/releases/latest).

Run the installer on the PC you want to update and approve the Windows administrator prompt. If you run it during a Reach session, reconnect after setup restarts the service.
